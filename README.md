# pstack

This repository contains the runtime-neutral fork of [pstack](./pstack/): an opinionated stack of Agent Skills for rigorous engineering work.

The skills preserve pstack's original principles, playbooks, prompts, and voice while replacing runtime-specific interfaces with capability-based equivalents that work across agent runtimes.

See [pstack/README.md](./pstack/README.md) for installation, usage, and the complete skill catalog.
